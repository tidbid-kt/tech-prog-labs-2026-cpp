# Шаблон репозитория для лабораторных работ по курсу Технологии программирования 2026 (C++)

## Окружение

1. **Компилятор с поддержкой C++20**: GCC 11+, Clang 14+ или Visual Studio 2022 (MSVC);
2. **CMake 3.20 или новее**: [скачать тут](https://cmake.org/download/) (в Visual Studio и CLion он уже встроен);
3. **IDE** на выбор: CLion, Visual Studio 2022 или VS Code с расширением CMake Tools.

## Как начать работу с проектом

1. Сделайте fork к себе на GitHub (инструкция [тут](https://docs.github.com/ru/pull-requests/how-tos/work-with-forks/fork-a-repo)).
2. Склонируйте свой fork и откройте папку проекта в IDE как CMake-проект.
3. Можно приступать к работе!

Если у вас уже есть свой репозиторий с прошлыми лабами, форк делать не обязательно: можно скопировать к себе нужные
папки из этого репозитория.

## Структура

Для каждой лабораторной работы выделена отдельная папка:

| Папка       | Лаба   |
|-------------|--------|
| `labs/lab2` | Лаба 2 |
| `labs/lab3` | Лаба 3 |
| `labs/lab4` | Лаба 4 |
| `labs/lab5` | Лаба 5 |
| `labs/lab6` | Лаба 6 |
| `labs/lab7` | Лаба 7 |

В каждой папке уже заведен шаблонный `main.cpp`. Все `.cpp` из папки лабы собираются автоматически, отдельно
прописывать новые файлы в `CMakeLists.txt` не нужно. Подключать заголовки внутри лабы можно от корня ее папки:
`#include "core/dice.hpp"`.

Из `main.cpp` собирается программа лабы, а если в папке лабы есть `demo.cpp` со своей функцией `main`, из него
отдельно собирается вторая программа.

## Как запустить код

Из корня репозитория:

```bash
cmake -S . -B build
```

```bash
cmake --build build
```

После сборки программа каждой лабы лежит в папке `build/labs/labN`: например, `build/labs/lab2/lab2`, а программа из
`demo.cpp` - рядом, `lab2_demo`. В Visual Studio программы лежат на уровень глубже, в папке конфигурации: например,
`build\labs\lab2\Debug\lab2.exe`.

## Русский текст в консоли Windows

Чтобы русский текст выводился в консоли Windows, в начале программы переключите консоль в UTF-8: вызовите
`SetConsoleOutputCP(CP_UTF8)` и `SetConsoleCP(CP_UTF8)` из `<windows.h>`. Если текст все равно выводится
кракозябрами, запускайте программу из Windows Terminal. Если не получается ввести текст на кириллице, введите его
латиницей.

## После выполнения лабораторной

После выполнения лабораторной работы необходимо закоммитить и запушить итоговый код.

Коммиты будут идти в ваш fork, не в оригинальный репозиторий.

При появлении изменений в оригинальном репозитории на GitHub откройте свой fork и нажмите кнопку **Sync fork** после чего выполните `git pull` в терминале.
